# QQ 会话刷新设计

## 目标

让通知助手准确显示当前 QQ 会话，并让功能模组的目标选项及时反映新增或更换的会话。

## 方案

以 QQ Bot 的 `model-prefs.json` peer 映射确定会话身份，再关联宿主会话列表。放弃通过进程工作目录和 ID 前缀猜测身份。群名缓存只提供展示资料，上游当前映射优先。页面将“刷新会话”（只读取本地状态）与“同步群名”（请求 QQ 接口并更新标题）分开。

曾考虑继续扫描宿主全部会话并改进过滤，以及增加服务端事件推送。前者仍无法可靠识别 QQ 会话；后者需要更多宿主和浏览器生命周期代码。当前采用本地读取、打开下拉框时刷新、页面恢复时刷新及可见时轻量轮询。

## 行为约束

- 会话不存在、已归档或未映射的 ID 不进入可选目标；诊断表保留映射缺失信息。
- 刷新期间保留当前列表，旧请求不得覆盖新请求。
- 已选目标失效时明确提示，保存或运行前要求重新选择。
- QQ 接口失败不影响本地会话刷新。
