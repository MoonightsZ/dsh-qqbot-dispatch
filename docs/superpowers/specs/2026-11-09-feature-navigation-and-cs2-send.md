# 功能导航与 CS2 立即发送

功能页保留顶部“会话 / 功能”切换；功能区域改为左侧模组导航、右侧配置面板。窄屏时导航移到配置面板上方并允许横向滚动。每次只展示一个模组，切换时保留尚未保存的表单内容。导航从功能清单生成，新增模组无需改导航结构。

CS2 赛事通知保留“立即检查”：读取已保存配置，只发送尚未通知的匹配赛事。新增“立即发送”：先保存当前表单，再按当前队伍和赛事等级筛选，发送所有匹配赛事，包括已通知过的赛事。手动发送允许在模组关闭时执行，但仍受目标群不可用检查、数据源可用性和 Liquipedia 限频约束。执行结果显示匹配和发送数量；没有匹配时提示“未找到匹配赛事”。定时执行继续去重。
