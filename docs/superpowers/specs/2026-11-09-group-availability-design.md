# QQ 群可用状态设计

群解散、机器人退群后，上游 peer 映射和本地会话可能继续存在。通知助手保留历史和配置，但不能继续向已确认不可用的群提交任务。

仅在群消息发送接口返回 HTTP 404 时，将该群对应的当前会话标记为“群不可用”。群信息查询的 404 不能证明群已解散，因此不改变状态；限流、超时、鉴权和服务端错误也不改变状态。状态保存在插件自己的文件中，与当前 peer 和 sessionId 同时匹配才生效；成功查询群信息可恢复。官方退群事件若将来由上游暴露，可接入同一状态入口。界面保留会话，显示状态，不把它列为功能目标。群不可用时，赛事通知和偶尔闲聊都在实际提交前停止，不自动删除会话、配置或上游映射。

曾考虑同步失败即删除映射，或对所有错误暂停发送。前者可能破坏会话历史，后者会把临时故障误判为永久不可达，因此均不采用。
