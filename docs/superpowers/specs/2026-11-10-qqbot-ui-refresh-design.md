# QQ 机器人通知助手界面优化设计

## 目标与范围

让侧栏页面在 DSH 明暗主题和不同宽度下更易读、更易操作。统一会话、功能模组、全局配置三页的视觉层级、控件状态与反馈方式；保留现有功能、路由、配置格式和投递逻辑。

## 方案选择

| 方案 | 取舍 |
| --- | --- |
| DSH 原生风格（已选） | 沿用宿主语义颜色、字体和圆角；借鉴 dsh-context 的紧凑信息卡与 dsh-media-desk 的控件状态，并用归藏设计的细线和清晰标题组织页面。可同时适配明暗主题。 |
| 归藏编辑风格 | 版式辨识度更强，但独立配色和字体更容易与宿主主题冲突。 |

## 页面设计

- 页头保留插件名称、简短用途与会话刷新操作；减少重复说明和技术细节，把操作放在对应页面。
- 顶层导航保留“会话 / 功能 / 配置”，强化当前页和键盘焦点；功能页继续采用左侧模组导航，窄屏改为可横向选择。
- 会话页将标题、类型、状态、最后活动和群名操作按重要程度排列；窄屏用分块行布局，避免表格横向挤压或溢出。
- 模组配置采用统一的卡片边界、字段间距、帮助文字、操作区和状态反馈。内置与扩展模组共用这些视觉约定，专属配置仍由各自卡片提供。
- 全局配置突出当前投递方式及其实际效果；提示说明与操作靠近，保留直接发送模式的实例条件提醒。
- 使用 DSH 语义颜色和主题变量，避免固定亮色或暗色。统一 hover、focus-visible、disabled、loading、成功与失败状态；减轻重复的厚重阴影。

## 验证

现有交互测试覆盖导航、会话表、模组卡片和配置行为；补充窄屏布局与状态语义检查。运行完整测试及前端构建。若可在本机打开 DSH 页面，再检查宽屏、窄屏和明暗主题的实际效果。
