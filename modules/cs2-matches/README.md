# CS2 赛事通知

按各条规则设定的间隔或 Cron 检查 Liquipedia 赛程，筛选关注队伍与赛事等级，并向指定 QQ 会话发送通知。

## 配置与操作

数据源、关注队伍、赛事等级和目标会话由本模组共用。目标会话可同时选择群聊和私聊，最多 20 个；不选择时继承[整组全局默认目标](../../README.md#全局默认目标会话)，单独选择则由模组目标组整体覆盖全局设置。队伍与等级留空时不按对应条件筛选。

每条规则按目标顺序处理。已通知记录按目标分别保存；一个目标失败时其余目标继续，之后「立即检查」仅补发尚未成功的通知。「立即发送」会对当前目标组逐个重发。结果中的「已提交服务回合」或「已调用上游发送」不代表 QQ 客户端已送达。

每日汇总、赛前提醒与赛果提醒各有开关、检查计划、下次执行时间、运行结果和立即操作，可以同时启用。同一场比赛可以先进入每日汇总，开赛前收到提醒，完赛后再收到赛果。模组总开关关闭时，规则都不会自动运行。新配置只预选每日汇总，模组总开关仍默认关闭；旧配置升级后只保留仍存在的原规则。若旧配置只使用已移除的通知方式，三条规则均保持关闭，需手动启用所需规则。

| 通知规则 | 发送范围 | 默认检查计划 |
| --- | --- | --- |
| 每日汇总（新配置默认） | 按当前时区（默认 `Asia/Shanghai`）汇总今日或明日赛程；同一日期最多自动发送一次。仅包含检查时 Liquipedia 当前可见的赛事，之后新出现的赛事不会自动补入已发送的汇总。内容较长时会分段发送。 | 每天 18:00 的 Cron（默认） |
| 赛前提醒 | 赛事开赛时间进入“最多提前提醒”窗口后，在首次检查时发送一次；开赛后不补发。提前量可设为 15–360 分钟，默认 60 分钟。 | 每 15 分钟检查，初始关闭 |
| 赛果提醒 | 仅发送 Liquipedia 已明确标记完赛、双方比分有效且开赛时间在最近 6 小时内的比赛；进行中比分、无比分及 `0:0` 不发送。公开接口没有完赛时间，因此超长比赛可能在窗口外才完赛。按场次去重，手动「立即发送」可重发符合条件的赛果。 | 每 15 分钟检查，初始关闭 |

检查计划只决定何时读取赛程，不决定通知包含哪些比赛。例如 `0 18-23 * * 1-5` 会在工作日 18:00–23:00 每小时检查一次；每日汇总仍只在该日期首次成功检查时发送。三条规则的计划可分别调整。

多条规则同时到期时，自动检查按「赛前提醒 → 赛果提醒 → 每日汇总」的优先级进行。前一条规则确实提交或发送了通知后，下一条至少等待 30 秒，并在间隔到期后的下一次调度检查中继续处理；没有匹配内容的检查不占用间隔。待检查的规则会保存在配置中，重启后继续处理，超过 1 小时的待检查项会失效。赛果提醒按原到期时间判断 6 小时窗口，避免仅因错峰而漏发。服务回合的实际到达顺序仍由上游决定，间隔只约束插件提交时间；同一规则生成多条消息时仍可能连续出现。手动操作不受该间隔限制。

| 操作 | 效果 |
| --- | --- |
| 立即检查 | 在对应规则中按已保存的设置处理尚未通知过的匹配赛事。 |
| 立即发送 | 在对应规则中先保存当前配置，再重发匹配赛事，包括已通知过的赛事。 |

页面显示匹配数量与发送或提交数量。发送失败的赛事不会被记录为已通知；服务回合提交成功仍不代表 QQ 已送达。

## Cron 规则

每条通知规则可分别选择间隔或 Cron。Cron 表达式使用独立输入框，以数组保存。页面会解释表达式，并显示按设定时区计算的下一次执行时间；修改后需保存才会更新。

支持五段格式「分 时 日 月 周」、`*`、`*/步长`、数字列表和范围。日期与星期同时指定时须同时满足。旧版以 `;` 分隔的规则仍可读取，保存后转为数组。

## 内容生成方式

「固定赛事内容」（默认）提交已排版的赛事正文；「AI 焦点分析」让 Agent 根据赛事数据和已有会话上下文，在可编辑的 Markdown 模板中填写焦点分析。分析不自行联网，也不应编造战绩、阵容或胜率。

固定内容按通知用途分别排版：每日汇总按赛事分组列出当天比赛；赛前提醒以「即将开赛」对阵卡展示同赛事的对局、开赛时间和可用的 Bo 信息；赛果提醒显示已确认比分，比分不等时标出胜者，比分相等时只显示比分。三者都保留 Liquipedia 来源与 CC BY-SA 3.0 标注，不生成比赛过程或胜负原因。设置页预览与实际发送使用同一套排版。

每日汇总、赛前提醒和赛果提醒各有一套模板，通过「模板选择」切换编辑对象；这不会改变规则开关。赛果分析只能依据已确认比分与会话上下文，不得补造地图、回合或胜负原因。已有自定义模板升级时会复制到赛前提醒，并将其中的赛事标题、对局占位符转换成每日汇总所需的日期标题、分组赛程占位符。

每日汇总默认模板：

```md
# {{title}}

## 赛程总览
{{schedule}}

## 赛事看点
{{focusAnalysis}}

---
数据来源：[Liquipedia]({{sourceUrl}}) · CC BY-SA 3.0
```

赛前提醒默认模板：

```md
# {{tournament}}

{{tier}}

## 即将开赛
{{matchups}}

## 赛前焦点
{{focusAnalysis}}

---
数据来源：[Liquipedia]({{sourceUrl}}) · CC BY-SA 3.0
```

赛果提醒默认模板：

```md
# {{tournament}}

{{tier}}

## 最终比分
{{results}}

## 赛果看点
{{focusAnalysis}}

---
数据来源：[Liquipedia]({{sourceUrl}}) · CC BY-SA 3.0
```

每日汇总模板必须保留 `{{schedule}}`、`{{focusAnalysis}}`、`{{sourceUrl}}`；赛前提醒模板必须保留 `{{matchups}}`、`{{focusAnalysis}}`、`{{sourceUrl}}`；赛果模板必须保留 `{{results}}`、`{{focusAnalysis}}`、`{{sourceUrl}}`。三者都必须标注 Liquipedia 来源。全局切换到直接发送 Markdown 时，页面隐藏内容设置，改用示例赛事预览实际发送格式并标明原因；只发送固定赛事正文。已保存的内容生成方式与模板仍会保留，切回服务回合投递后可继续编辑。投递方式见[根目录说明](../../README.md#全局投递配置)。
