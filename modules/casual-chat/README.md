# 偶尔闲聊

在指定 QQ 会话定时检查触发条件，偶尔发起简短聊天。模组默认关闭。

## 自动触发

| 设置或限制 | 默认值 |
| --- | --- |
| 每日检查时间 | 19:00，时区 `Asia/Shanghai` |
| 触发概率 | 30% |
| 安静时段 | 22:00–09:00 |
| 距上次发送的冷却时间 | 至少 3 天 |
| 滚动 7 天发送上限 | 最多 2 次 |
| 目标会话近期活动 | 最近 6 小时有活动则跳过 |

检查时间、概率、冷却天数、安静时段和话题提示均可在功能页修改。多个话题用 `|` 分隔；留空时使用内置话题。

「立即发起」会先保存当前设置，再跳过自动触发限制。

## 投递方式

全局选择服务回合投递时，Agent 结合已有会话上下文生成开场白；选择直接发送 Markdown 时，选中的话题会作为开场白原文发送。全局开关及限制见[根目录说明](../../README.md#全局投递配置)。
