# 偶尔闲聊

在指定 QQ 会话定时检查触发条件，偶尔发起简短聊天。模组默认关闭；可同时选择最多 20 个群聊和私聊。目标会话不选择时继承[整组全局默认目标](../../README.md#全局默认目标会话)，单独选择则整体覆盖全局设置。

## 自动触发

| 设置或限制 | 默认值 |
| --- | --- |
| 每日检查时间 | 19:00，时区 `Asia/Shanghai` |
| 触发概率 | 30% |
| 安静时段 | 22:00–09:00 |
| 距上次发送的冷却时间 | 至少 72 小时，可设为 1–720 小时 |

检查时间、概率、冷却小时数、安静时段和话题池均可在功能页修改。每个目标独立计算冷却并记录上次话题；一个目标发送失败不阻止其他目标。已有按天保存的冷却配置会自动换算为小时；旧的 `|` 或换行分隔话题会自动迁移为列表。

## 话题池与 AI 推荐

每条话题可以启停、编辑、删除，并配置多个标签。输入主题词后点击“AI 推荐”，可编辑和勾选候选；点击“加入话题池”后，还需点击页面“保存”才会生效。推荐使用 DSH 已配置的首个可用模型；没有可用模型时仍可手动维护话题。生成时的主题词会单独保留，默认也用作新话题的标签（主题词超过标签长度上限时只保留来源）。AI 推荐不会读取 QQ 会话内容，也不会自动向 QQ 发送消息。

抽取时先等概率选择一个有启用话题的标签，再在标签内随机选话题；多标签话题按标签数降低单次权重，并尽量避开上一条已提交投递链路的话题。无标签话题归入“未分类”。若池为空，使用三个内置话题；若池中话题全部禁用，则跳过发送。

「立即发起」会先保存当前设置，再跳过自动触发限制。

## 投递方式

全局选择服务回合投递时，Agent 结合已有会话上下文生成开场白；选择直接发送 Markdown 时，选中的话题会作为开场白原文发送。全局开关及限制见[根目录说明](../../README.md#全局投递配置)。
