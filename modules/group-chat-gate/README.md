# 群聊频控

这个模组默认关闭，启用后实时处理 QQ Bot 收到的所有群聊消息，不需要选择目标会话，也不按 Cron 或间隔运行。它仅对未 @ 机器人的纯文字群消息生效；私聊、@ 消息和带附件的消息直接交给上游 QQ 插件。附件管理员审批不在本模组内。

要让频控处理普通群消息，官方 `im-qqbot` 配置须设 `requireMention: false`，且 QQ 平台须向机器人下发群聊全量消息。没有平台授权时，本模组无法读取未 @ 的消息。

## 配置

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| 接话概率 | 30% | 防抖结束后决定是否将消息送入 Agent；未命中时加入积压。 |
| 静默合并 | 30 秒 | 同一群持续发言时重置计时；安静到时合并成一次入站消息。设为 0 时立即处理。 |
| 每群积压上限 | 30 条 | 未命中概率或达到限速的文字，最多保留多少条供下次命中时附带。设为 0 则不保留。 |
| 最短间隔 | 0 秒 | 同一群两次送入 Agent 的最短间隔；0 不限制。 |
| 每小时上限、每天上限 | 0 | 按群限制送入 Agent 的次数；0 不限制。每日按 `Asia/Shanghai` 换日。 |
| 过滤无效文字 | 开启 | 丢弃空白、纯符号、短于两字、短重复字符和纯语气词。 |

@ 机器人时，当前群的积压与尚在等待的文字会附在当前消息前面，再交给上游处理。群与群之间不会混合。群状态只保留在运行内存中，重启或关闭模组会清空积压与限速计数；每个群的待处理文字和活跃群数量都有上限。

设置保存在 `~/.dsh-qqbot/dispatch-features.json`。保存后新消息立即使用新设置。该模组只控制入站消息，**不会限制** CS2 通知、偶尔闲聊或其他主动发送，也不能扩大 QQ 平台的主动消息额度。

若同时启用 `dsh-qqbot-expands` 的群聊频控，本模组会让对方的频控优先处理，避免两层频控重复拦截。请只保留一套频控配置。
